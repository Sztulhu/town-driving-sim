# Town Driving Sim

Playable browser-based 3D driving sandbox prototype.

## Play online
Enable GitHub Pages in repository settings using the `main` branch and `/ (root)`. The included workflow also deploys automatically when GitHub Actions is enabled.

## Controls
- WASD or arrow keys: drive
- Space: handbrake
- R: reset

## Current features
- Procedural small-town environment with roads, buildings, trees and sidewalks.
- Three selectable vehicles with different acceleration, top speed and grip.
- Traffic vehicles and reckless driving encounters.
- Wanted level and police pursuit.
- Speed-limit HUD, damage bars, collision feedback and chase camera.

This is an intentionally lightweight browser prototype. Detailed deformable vehicle meshes, full road-graph traffic rules and production-grade suspension simulation remain future milestones.
