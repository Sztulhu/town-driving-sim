# Town Driving Sim

Playable browser prototype of a procedural small-town driving sandbox.

## Run
Open `index.html` in a modern browser. It uses Three.js from a public CDN, so an internet connection is required.

Controls: WASD/arrows to drive, Space to brake, R to reset.

This is a prototype foundation: procedural town, three vehicles, traffic, wanted system, police pursuit, HUD, collisions and performance damage. Advanced deformable meshes, detailed suspension simulation and production assets are planned for later iterations.
